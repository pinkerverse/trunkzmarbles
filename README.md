# TRUNKZ Marbles

Mobile-first TRUNKZ marble racing PWA: six original pastel colors, head-only racers, countdown sound, physics obstacles and an Instagram-friendly winners podium.

## How to publish

Go to **Settings → Pages** in this repository, choose **Deploy from a branch**, select `main` and `/(root)`, and save. The live address will be `https://pinkerverse.github.io/trunkzmarbles/` after the deployment succeeds.

## Install on iPhone

Open the live URL in Safari, use **Share → Add to Home Screen**, and use iOS Screen Recording for vertical Instagram Reels.

No external scripts, embedded binary blobs, trackers, or external dependencies. The app uses local, editable SVG character illustrations. This repository is separate from Wiggle Doodle and OASIS.
