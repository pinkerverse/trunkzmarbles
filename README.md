# TRUNKZ MARBLES · black & white edition

A mobile-first, standalone offline-capable PWA for 9:16 Instagram Reels.

- Six pastel marbles use the **same traced illustration of the supplied TRUNKZ head**, without a body. The original artwork was vectorized, retaining its outline, eye shapes, mouth, and curved upper detail.
- **PICK A MARBLE** appears directly above the actual starting rail; tap the marbles to choose your favorite, then **START RACE**.
- Count down **3, 2, 1, GO** with optional device audio automatically enabled by the start tap; no sound toggle.
- **Three courses:** Zigzag, Split Paths, and Funnel Frenzy. All obstacles, rails, funnels, backgrounds and podiums are black/white/gray.
- The camera follows the leading marble. Each race is capped at approximately 8 seconds of action, with ranking based on actual finish order plus progress if fewer marbles have reached the line by the time limit.
- Add to iPhone Home Screen using Safari's **Share → Add to Home Screen**, then use iOS screen recording for Reels.

No dependencies, ads, accounts, analytics, tracking, or network calls from application JavaScript. The assets are readable SVG files, not Base64 encodings.

Only repository `pinkerverse/trunkzmarbles` should contain this project.
